# MGNREGA Dashboard Analysis (Excel Project)

Project Overview

This project presents a comprehensive **Excel dashboard** analyzing data from the **Mahatma Gandhi National Rural Employment Guarantee Act (MGNREGA)**. It focuses on key indicators such as **employment generation**, **women's participation**, **expenditure patterns**, and **work progress**, offering a data-driven insight into the scheme’s performance.

---

 Dataset Description

The dataset includes over **50,000 rows and 12+ columns**, covering:

- State and district-level employment data
- Number of households provided work
- Total person-days generated
- Percentage of women participation
- Fund allocation and expenditure
- Type of work completed

---

 Tools and Technologies

- **Microsoft Excel**
  - Pivot Tables & Pivot Charts
  - Advanced Charting Techniques
  - Data Cleaning and Filtering
  - Conditional Formatting
  - Interactive Dashboards (Slicers, Buttons)

---

 Key Features

- 📈 **Trend Analysis:** Employment and expenditure over time  
- 👩‍🌾 **Gender Insights:** Women’s participation visualization  
- 💸 **Fund Utilization:** Comparison of allocated vs. spent amounts  
- 📍 **Region-Level Breakdown:** State and district-wise performance  
- 📊 **Interactive Filters:** Dynamic view with slicers for better user experience
